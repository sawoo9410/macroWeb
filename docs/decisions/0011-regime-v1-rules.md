# ADR-0011 — 레짐 탐지기 v1: 지금 있는 데이터로만 판정하는 규칙

- 날짜: 2026-11-03 · 상태: 채택 · 관련: PLAN §9.2(레짐), §9.4(교차자산 정합성), §9.7(논제 원장), ADR-0005(키 없는 데이터), ADR-0010

## 맥락
PLAN §9.2 의 레짐 표는 FOMC 결정·점도표·FedWatch·WALCL·RRP·TGA·HY 스프레드·외국인 순매수 등을 입력으로 쓴다. 2026-11-03 현재
들어오는 것은 ADR-0005 의 키 없는 시계열(재무부 수익률·Naver 지수·ECB 환율·Kraken BTC)과 Kalshi/Polymarket 확률뿐이다.
FRED·ECOS·KRX 는 키/어댑터 뒤다(Q16·Q17).

## 결정
1. 축별 규칙과 임계값은 `config/regime.yaml` 에 두고 코드는 읽기만 한다. 입력이 없는 축은 **"자료 없음"** 으로 출력한다(유동성 축은 FRED 전까지 판정 안 함).
2. v1 입력: 금리 = UST 2Y 28일 변화(±0.15pp) + 다음 FOMC 의 Kalshi 25bp 인상 확률(≥0.5 면 "인상 우세"); 달러 = DXY 28일 변화(±1.5%) + 원화 방향; 위험선호 = VIX 수준(25/15) + BTC; AI = SOX 28일 변화(+5%/−8%); 한국 수급 = KOSPI·USD/KRW 28일 방향의 **대리 지표**(KRX 외국인 수급 전까지 "(대리)" 표기).
3. 매주 `regime_week` 에 스냅샷을 남기고 축의 핵심 상태 단어가 지난주와 다르면 리포트 맨 위 경보(`alert_on_change`).
4. 교차자산 정합성 v1: 캘린더 14일 내 이벤트 노드에서 전파한 예측 부호와 자산 노드(`data_key`)의 7일 실제 변화를 비교해 확인/불일치/무반응으로 분류한다. 불일치는 chief-editor 필수 입력이자 "시장이 다르게 본다" 후보.
5. 논제 원장 v1: `thesis add/list/score/auto-score`. `auto_json`(market_key·op·threshold)이 있으면 만기 뒤 market 값으로 자동 채점(Brier), 없으면 `due` 로 표시해 사람이 채점한다.
6. 차트 v1: 스냅샷 시계열 7개의 60일 선그래프(chart 스킬 규약: 색=부호, 한글 폰트, 캡션에 출처·기준일·[F]).

## 결과
- 임계값은 시작값이다(§0.4). 8주 분포가 쌓이면 재보정하고 이 ADR 에 추가한다.
- 유동성 축이 비어 있는 동안 리포트는 "유동성 자료 없음" 을 그대로 쓴다 — 숫자를 만들지 않는다.
- FRED 키가 들어오면 `config/regime.yaml` 의 `liquidity.inputs` 를 그대로 쓰고 규칙만 추가하면 된다(코드 변경 없음).
